# Contributing to Awesome DeFi AI Skills

Thank you for your interest in contributing! This is a curated list, so quality matters more than quantity.

## How to Add an Entry

1. Fork the repository
2. Add your entry in the appropriate section of `README.md`
3. Submit a pull request

## Entry Format

Use this format for new entries:

```markdown
### Tool Name

- **Repo:** [github.com/org/repo](https://github.com/org/repo)
- **Install:** `command to install`
- **Chains:** List of supported chains

Brief description of what the tool does and its key capabilities.
```

## What Belongs Here

- AI skills files (installable via `npx skills add` or similar)
- MCP servers focused on DeFi, blockchain, or crypto market data
- Agent toolkits with on-chain capabilities
- Skills marketplaces and directories

## What Does NOT Belong Here

- General-purpose blockchain libraries (ethers.js, viem, web3.py)
- Wallets or browser extensions without AI/agent integration
- Centralized exchange APIs without DeFi functionality
- Unmaintained projects (no commits in 12+ months)

## Quality Standards

- The project must be publicly accessible (or have public documentation)
- Include a working install command or link to setup instructions
- Describe capabilities accurately — no marketing fluff
- Verify that all links are working before submitting

## Updating Existing Entries

If you spot outdated information, broken links, or missing capabilities, open a PR with the fix.
